# Web Development Discovery Piscine

## Overview

My work from the **Web Development Discovery Piscine**, a 5-day intensive program covering the basics of web development: HTML, CSS and JavaScript.

| Cell | Description | Technologies |
|------|-------------|--------------|
| `cell00` | Basic shell commands for directory manipulation | Shell |
| `cell01` | HTML structure, tables and responsive design | HTML |
| `cell02` | Dropdown menu, profile card and parallax effect | CSS |
| `cell03` | Background color change, balloons, to-do list and calculator | JavaScript |

## Concepts Learned

- **Structure:** HTML pages, tables and responsive design
- **Styling:** CSS layouts, dropdown menus, profile cards and parallax scrolling
- **Interactivity:** DOM manipulation and events such as `onclick`
- **Persistence:** saving to-do items with cookies
